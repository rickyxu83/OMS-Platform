# 016 智能报表：明细钻取 + 订阅增强

## 背景

批次 1/2 后报表能看聚合数据，但看到"张三 30 单"就止步了，没法看是哪 30 单；订阅只有周/月频率，且推送失败无人知晓。

## 需求

### 1. 明细钻取（本期只做工单数据集）

- 报表结果行可点击 → 跳转工单列表页，自动带上对应该行的筛选
- 跳转参数：时间范围（startDate/endDate）+ 维度值作为 keyword 搜索词
  - 工单列表页已支持 keyword/startDate/endDate URL 参数，无需改列表页
  - 时间维度行（如"2026-08"）：date 范围收窄到该月/周/日
  - 多维度行：keyword 取各维度值空格拼接（后端多词 AND 搜索）
- 其他数据集（工时/考勤/巡检/设备/MR/备件/值班/假期/采购）本期不做，行不显示链接
- 交互：表格行 hover 显示"查明细"图标；整行点击即跳转（新标签页打开，不丢报表上下文）

### 2. 订阅增强

- frequency 增加 `daily`（每天 09:07 推送，复用现有 scheduler 时点）
- 推送失败可感知：
  - `report_subscriptions` 增加 `last_error` / `last_attempt_at` 字段（ensure 惰性 ALTER）
  - 推送失败时记录错误，模板列表上该报表显示警示图标（hover 显示错误与时间）
  - 不额外发告警邮件（邮件通道本身就挂了时发告警也到不了）

## 影响面

- 前端：`SmartReport.tsx`（行链接）、模板列表警示图标
- 后端：`report/engine.js`（rows 附带 drilldown 链接所需的时间范围已有，无需改）、`subscriptions.js`/`scheduler.js`（daily + 错误记录）、`store.js`（新字段）
- 测试：store/订阅相关现有测试扩展 daily 分支

## 非目标

- 非工单数据集的钻取
- 报表内嵌明细弹窗（用跳转代替）
- 订阅失败的重试机制
