# 018 智能报表：巡检完成率数据集 + 摘要禁个人对比

## 背景

巡检计划数据集只能统计"计划本身"，答不了管理核心问题"巡检执行的怎么样、漏没漏"。口径已与佬确认（2026-09-20）。另外佬要求 AI 摘要不要出现工程师/销售等个人之间的对比。

## 口径（佬已确认）

1. **应巡次数按周期折算**：月检=范围内每个自然月 1 次；双月检=每月 0.5 次；季检=每月约 0.33 次。折算依赖时间范围，"全部时间"下显示 0（口径上无意义）
2. **已执行 = 已生成工单**（漏没漏的视角）；工单是否结案单独给指标

## 方案

### 新数据集 `inspection_completion`（巡检完成率）

- 粒度：巡检计划（每计划一行参与分组），订单用**预聚合子查询** LEFT JOIN，避免扇出重复计数
- **无时间字段**：统计区间只作用于指标折算与工单匹配（`:timeFrom`/`:timeTo` 参数），不筛计划行
  - 引擎扩展：数据集可不声明 timeFields（跳过时间 WHERE；params 恒含 timeFrom/timeTo，无界为 NULL）
- 维度：客户、负责工程师、巡检周期、是否启用
- 指标：
  - `plans` 计划数 = COUNT(*)
  - `expected` 应巡次数(折算) = SUM(周期系数 × 范围内月数)，NULL 安全
  - `generated` 已生成工单数 = SUM(子查询订单数)
  - `closed` 已结案数 = SUM(子查询结案数)
- 筛选：客户/工程师文本、周期枚举、是否启用枚举（默认建议查启用中的计划）

### 摘要 prompt 调整（佬要求）

SUMMARY_PROMPT 增加：不对工程师/销售等个人之间进行对比或排名，只总结总体结果。
缓存键加入 prompt 版本号（prompt 变更后旧摘要自然失效）。

## 影响面

- `report/engine.js`（timeFields 可选化）、`datasets.js`、`assistant.js`
- 测试：无时间字段数据集的 validateSpec/buildQuery、折算指标 SQL 参数

## 非目标

- 漏检的精确日期级展开（折算口径已注明估算）
- 巡检明细钻取
