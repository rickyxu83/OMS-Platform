# MR 合约用印流程

> 目的：销售开 MR 单涉及合同时，把“未盖章合约 → 助理走用印 → 回填盖章合约与合同编号”这个环节固化进系统，避免口头交接遗漏。
>
> 确认要点（2026-10-14）：选了“有合同”就必须有合约文件；邮件只通知对应助理，不抄送；单据只保留盖章合约（未盖章件在助理上传盖章件后自动删除）。

## 角色

- **销售（业务负责人）**：MR 单填写人
- **助理**：负责合约用印流程对接（走内部用印系统）
- **系统**：OMS 运维智管 MR 模块

## 完整流程

### 第一步：销售建单

1. 销售填写 MR 单，在「合同与罚则」栏位选择 **"有合同"**
2. 栏位内出现「合约附件」上传位，销售**必须上传未盖章合约**（不上传无法提交，系统会提示）
3. 合同编号此时**可以留空**（合同流程还没走完），也可以先填
4. 合约文件有专用上传位，和报价等其它附件分开放，单据里能一眼看出哪份是合约

> 若选"无合同"：不需要上传合约，流程与现在完全一样，无任何变化。

### 第二步：提交后系统自动通知助理

5. 销售提交 MR 单后，系统自动给对应助理**发邮件**：
   - 邮件**附上未盖章合约文件**
   - 提示助理：这张 MR 有合同，请走合约用印流程，完成后回到 MR 单上传盖章合约并填写合同编号
6. 同时 MR 单照常进入签核流程，第一站就是助理

### 第三步：助理走用印流程（线下/内部系统）

7. 助理收到邮件，拿合约去内部系统走用印流程
8. 用印完成后拿到：**盖章合约文件 + 合同编号**

### 第四步：助理回填 MR 单

9. 助理打开 MR 单（待办中心或邮件链接均可进入），在「合同与罚则」栏位：
   - 上传**盖章合约**（上传后未盖章件自动删除，单据只保留盖章件，带“盖章”标记）
   - 填写**合同编号**（若销售已填，会预填，助理可核对修改）
10. 助理确认单据其它内容无误后点**"通过"**

### 第五步：系统把关

11. 助理点"通过"时系统检查：
    - 缺盖章合约 → 不放行，提示"请上传盖章合约"
    - 缺合同编号 → 不放行，提示"请填写合同编号"
    - 两者齐备 → 正常流转下一步签核
12. 后续签核（业务负责人/工程会签/处级/副总）与现在完全一样
13. 全部签核通过后，MR 单直接流转采购（编号已齐，不再卡顿）

## 特殊情况处理

| 情况 | 处理方式 |
|---|---|
| 助理主管代签 | 代签时可以代传盖章件、代填编号 |
| 单据被驳回 | 已填的编号和合约文件保留，修改后重新提交即可 |
| 驳回后改成“无合同” | 保存时合约附件（含盖章件）**自动删除**，系统会先弹确认框 |
| 销售提交时已有合同编号 | 编号预填，但**盖章合约仍必须由助理补传**（有编号不代表已盖章） |
| 历史已签核的旧单 | **不受影响**，完全按老样子 |
| 目前正在途、等助理补编号的单 | 按老流程补完编号即可，不强制补盖章件 |

## 对现状的改变（一页看懂）

| 环节 | 现在 | 新流程 |
|---|---|---|
| 合约上传位置 | 混在通用附件区 | 「合同与罚则」栏位专用上传位 |
| 未盖章合约 | 不强制 | 选"有合同"则必填 |
| 助理得知要送印 | 靠口头/线下通知 | 系统自动发邮件给对应助理，附合约文件 |
| 盖章合约 | 无上传入口 | 助理签核时在栏位内上传（未盖章件自动删除，只留盖章件） |
| 合同编号补填时机 | 签核全过后、采购前 | 提前到助理签核时 |
| 卡控点 | 采购前发现缺编号才挂起 | 助理签核步直接把关，缺件不让过 |
