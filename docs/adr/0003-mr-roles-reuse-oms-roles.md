# MR 签核角色复用 OMS 现有角色，不新增角色

MR 签核链的五个位置直接映射到 OMS 现有角色，不新建角色：

| 签核位 | OMS 角色 |
|---|---|
| 助理 | `assistant` |
| 业务 | `sales` |
| 工程会签（装机勾「敦阳」时） | `engineering_supervisor` |
| 处级单位 | `sales_supervisor` |
| 副总（售价>75万 或 毛利率<15% 时） | `operations_director` |

原因：OMS 权限目录已有这些角色且带各自的可见范围（如 sales 按本人过滤），复用即获得登录、权限、审计等既有能力，权限目录无需改动。

代价：Excel 上的签核位名称与 OMS 角色名不同，代码/界面需显式维护这一映射；若未来签核人不再与角色一一对应（如按人指派），需要重新设计。
