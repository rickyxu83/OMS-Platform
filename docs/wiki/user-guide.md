## 1. 产品概览

OMS Platform 是面向现场运维、售后服务、客户资产和服务记录协同的平台。

系统以**管理工作台**为主，用于工单派发、工单填写、客户与资产维护、巡检计划、月报、用户、审计和系统设置。工程师侧填单已整合到管理端的 **工单填写** 入口。

## 2. 登录与工作台选择

1. 打开统一登录页：`https://<admin-domain>/login`。
2. 输入账号和密码。
3. 如果账号只有一个可用工作台，系统会自动进入。
4. 如果账号拥有多个工作台，请选择本次要进入的工作台。
5. 工程师账号可能需要先完成改密、资料补充、头像上传或手写签名等引导流程。
6. 多次登录失败后，账号可能会被临时锁定，请等待锁定结束或联系管理员。

## 3. 角色与权限

| 角色 | 管理端 |
|---|---|
| `engineer` | 使用工单填写入口，接口按本人过滤；可删除派给自己的 draft/assigned/rejected 工单、可作废本人已结案工单（有意设计） |
| `engineering_supervisor` | 可使用工单填写入口；派单管理可见全部工单 |
| `operations_director` | 按授权模块查看和管理全部工单 |
| `administrative_supervisor` | 查看管理端业务数据，不可派单、审批、编辑、删除或改系统设置 |
| `admin` | 平台全部权限 |

权限会在前端路由和后端接口同时校验。如果页面不可见或接口返回无权访问，请先确认账号角色和工作台权限。

## 4. 管理工作台

### 4.1 运营总览

- 查看工单总数、待处理、已完成和异常状态。
- 查看近期服务活动和工作量分布。
- 根据看板判断需要派单、催办或复核的事项。

### 4.2 工单处理

1. 根据客户请求或内部服务需求创建工单。
2. 填写客户、联系人、站点、设备、问题、优先级和期望服务信息。
3. 指派工程师或工程主管。
4. 跟踪处理过程中的状态变化。
5. 查看工程师提交的服务表和后续说明。
6. 服务完成后关闭或归档工单。

建议派单前先确保客户和设备信息准确，问题描述应清晰，便于工程师准备工具、备件和远程支持资料。

### 4.3 客户与资产

- 维护客户名称、站点、地址、联系人和电话。
- 维护设备型号、序列号、软件版本、保修信息和维保方。
- 仅在私有环境文件配置好地图 Key 后使用地图/位置搜索。
- 新建客户前先搜索，避免重复档案。

### 4.4 巡检、月报、用户和审计

- 巡检计划用于周期性客户或设备检查，可指派工程师并跟踪完成情况。
- 月报用于汇总服务活动和工时，正式导出前应检查缺失或异常记录。
- 用户模块用于账号、角色和工作台权限管理。
- 审计日志用于追踪登录、数据修改、导出和设置变更等敏感操作。

## 5. 工单填写入口

工程师和工程主管通过管理端 **工单填写** 页面提交现场、远程和内勤服务记录。

- 工程师仅处理本人相关工单和本人填写记录。
- 工程主管可根据权限查看派单管理，并可填写本人服务记录。
- 填单前应确认客户、联系人、设备、服务模块和附件要求。

## 6. 服务表完整流程

1. 进入管理端 **工单填写**。
2. 选择现场、远程或内勤填单。
3. 选择客户、联系人、地址和服务模块。
4. 按模块填写处理记录、附件、设备和备件信息。
5. 现场服务按要求完成客户签名或电子签字确认函。
6. 信息不完整时可手动保存草稿；复核无误后提交。
7. 提交后按业务需要分享或导出服务表。

提交前请确认客户、联系人、设备型号、序列号、时间范围、工时、故障描述和处理结果都准确完整，附件不包含无关隐私信息。

## 7. 草稿与提交

- 草稿需要手动保存，不会自动保存。
- 提交前请确认必填项、附件和签名状态。
- 网络异常时请等待连接恢复后再提交，避免重复提交。

## 8. 分享、导出与报表

- 提交后的服务表可先预览再分享。
- 导出的图片或文档应检查是否包含敏感信息。
- 月报应在当月服务表全部提交后生成。
- 如果报表数据异常，请检查服务类型、工时、工程师归属和是否存在未提交记录。

## 9. 隐私与数据安全

不得公开或提交真实客户名称、联系人、手机号、邮箱、地址、定位、工单号、故障描述、内部备注、设备序列号、资产编号、主机名、IP、工程师签名、Token、Cookie、密码、API Key、`.env`、SSH 目标、远程目录、生产域名和部署密钥。

对外分享截图前，请使用实心遮罩或马赛克。若前端地图 Key 或第三方 Key 曾公开暴露，请立即更换，并在服务商控制台配置域名或 Referer 白名单。

## 10. 常见问题

| 问题 | 建议检查 |
|---|---|
| 无法登录 | 检查账号状态、密码、锁定状态和后端服务可用性。 |
| 无法进入工作台 | 确认角色是否拥有对应工作台权限。 |
| 本人记录为空 | 确认工单分配和本人过滤逻辑。 |
| 服务表无法提交 | 检查必填项、签名、网络状态和附件大小。 |
| 草稿丢失 | 确认草稿已手动保存，并使用同一账号继续编辑。 |
| 地图搜索失败 | 检查后端地图 Key 和前端地图 JS Key 是否配置在私有环境文件中。 |
| 导出或分享失败 | 检查浏览器权限、文件大小，以及记录是否已提交。 |
