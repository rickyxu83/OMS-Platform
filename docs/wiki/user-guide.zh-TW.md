本文檔說明 OMS Platform 的日常使用流程，覆蓋登入、工作臺選擇、工單處理、服務表填寫和隱私注意事項。

## 1. 登入系統

1. 打開統一登入頁：`https://<admin-domain>/login`。
2. 輸入帳號和密碼。
3. 如果帳號擁有多個工作臺權限，請選擇要進入的工作臺。
4. 工程師帳號首次使用時，系統可能要求完成改密、資料補充或簽名設定等引導流程。

## 2. 工作臺權限

| 角色 | 工程師端 | 管理端 |
|---|---|---|
| `engineer` | 只查看並處理分配給自己或屬於自己的工單 | 不能登入 |
| `engineering_supervisor` | 使用 `mine=1` 時只看自己的工單 | 查看並派發全部工單 |
| `supervisor` | 不能登入 | 查看全部工單 |
| `admin` | 不能登入 | 全部權限 |

## 3. 管理工作臺

管理工作臺用於營運管理和後台協同。

- **營運總覽**：查看關鍵指標和工單狀態。
- **工單處理**：建立、派單、更新和審核服務工單。
- **客戶與資產**：維護客戶檔案、站點、聯絡人、設備資產和維保資訊。
- **巡檢計畫**：管理計畫性巡檢任務。
- **月報匯出**：匯出工時和服務統計。
- **成員與角色**：管理帳號、角色和工作臺權限。
- **操作審計**：查看系統操作記錄，便於追蹤。
- **系統設定**：按需配置郵件、AI 連通性和平台級參數。

## 4. 工程師工作臺

工程師工作臺用於現場服務和日常執行。

- **我的任務**：查看分配給自己的服務任務。
- **客戶資產**：服務前查詢客戶和設備資訊。
- **新建服務表**：填寫現場、遠端或內勤服務記錄。
- **離線草稿**：網路不穩定時先保存，恢復網路後再提交。
- **月報**：查看個人服務統計。
- **個人資料與簽名**：維護服務單中使用的工程師資訊和簽名。

## 5. 服務表流程

1. 打開目標工單，或直接新建服務表。
2. 選擇服務類型、客戶、聯絡人、站點和關聯設備。
3. 填寫服務內容、故障描述、處理結果、備件和工時。
4. 僅在必要且合規時上傳照片或附件。
5. 按要求確認工程師簽名和客戶確認資訊。
6. 資訊完整後提交；資訊不完整時先保存草稿。
7. 提交後可按需要分享或匯出服務表。

## 6. 隱私與資料安全

- 不要公開包含真實客戶、手機號、地址、簽名、Token 或 API Key 的截圖。
- 對外分享截圖前，請使用實心遮罩或馬賽克處理敏感資訊。
- `.env`、生產域名、SSH 目標、遠端目錄和部署密鑰應保存在本地私有檔案中。
- 如果前端地圖或第三方 Key 曾經公開暴露，請在服務商控制台更換，並配置域名或 Referer 白名單。

## 7. 常見問題

- **無法登入**：檢查帳號狀態、密碼是否正確，以及是否因多次失敗被鎖定。
- **無法進入工作臺**：確認目前角色是否擁有該工作臺權限。
- **工程師任務為空**：確認工單是否分配給本人，以及工程師端是否只過濾自己的任務。
- **地圖或位置搜尋失敗**：確認後端地圖 Key 和前端地圖 JS Key 已在私有環境檔案中配置。
- **附件上傳失敗**：檢查檔案大小、網路狀態和後端上傳配置。
