本文档说明 OMS Platform 的日常使用流程，覆盖登录、工作台选择、工单处理、服务表填写和隐私注意事项。

## 1. 登录系统

1. 打开统一登录页：`https://<admin-domain>/login`。
2. 输入账号和密码。
3. 如果账号拥有多个工作台权限，请选择要进入的工作台。
4. 工程师账号首次使用时，系统可能要求完成改密、资料补充或签名设置等引导流程。

## 2. 工作台权限

| 角色 | 工程师端 | 管理端 |
|---|---|---|
| `engineer` | 只查看并处理分配给自己或属于自己的工单 | 不能登录 |
| `engineering_supervisor` | 使用 `mine=1` 时只看自己的工单 | 查看并派发全部工单 |
| `supervisor` | 不能登录 | 查看全部工单 |
| `admin` | 不能登录 | 全部权限 |

## 3. 管理工作台

管理工作台用于运营管理和后台协同。

- **运营总览**：查看关键指标和工单状态。
- **工单处理**：创建、派单、更新和审核服务工单。
- **客户与资产**：维护客户档案、站点、联系人、设备资产和维保信息。
- **巡检计划**：管理计划性巡检任务。
- **月报导出**：导出工时和服务统计。
- **成员与角色**：管理账号、角色和工作台权限。
- **操作审计**：查看系统操作记录，便于追踪。
- **系统设置**：按需配置邮件、AI 连通性和平台级参数。

## 4. 工程师工作台

工程师工作台用于现场服务和日常执行。

- **我的任务**：查看分配给自己的服务任务。
- **客户资产**：服务前查询客户和设备信息。
- **新建服务表**：填写现场、远程或内勤服务记录。
- **离线草稿**：网络不稳定时先保存，恢复网络后再提交。
- **月报**：查看个人服务统计。
- **个人资料与签名**：维护服务单中使用的工程师信息和签名。

## 5. 服务表流程

1. 打开目标工单，或直接新建服务表。
2. 选择服务类型、客户、联系人、站点和关联设备。
3. 填写服务内容、故障描述、处理结果、备件和工时。
4. 仅在必要且合规时上传照片或附件。
5. 按要求确认工程师签名和客户确认信息。
6. 信息完整后提交；信息不完整时先保存草稿。
7. 提交后可按需要分享或导出服务表。

## 6. 隐私与数据安全

- 不要公开包含真实客户、手机号、地址、签名、Token 或 API Key 的截图。
- 对外分享截图前，请使用实心遮罩或马赛克处理敏感信息。
- `.env`、生产域名、SSH 目标、远程目录和部署密钥应保存在本地私有文件中。
- 如果前端地图或第三方 Key 曾经公开暴露，请在服务商控制台更换，并配置域名或 Referer 白名单。

## 7. 常见问题

- **无法登录**：检查账号状态、密码是否正确，以及是否因多次失败被锁定。
- **无法进入工作台**：确认当前角色是否拥有该工作台权限。
- **工程师任务为空**：确认工单是否分配给本人，以及工程师端是否只过滤自己的任务。
- **地图或位置搜索失败**：确认后端地图 Key 和前端地图 JS Key 已在私有环境文件中配置。
- **附件上传失败**：检查文件大小、网络状态和后端上传配置。
