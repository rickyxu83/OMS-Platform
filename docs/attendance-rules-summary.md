# OMS 考勤规则说明（完整版 · 供行政审核核对）

> 依据系统当前考勤模块的实际执行逻辑梳理（2026-08-28），所有触发条件、阈值、特例均经程序实测验证。本文按「申请类型与权限 → 时长计算 → 代理人 → 审批流程（全角色明细）→ 证明材料 → 休假余额 → 法定节假日与三倍工资 → 值班 → 报表 → 状态流转 → 管理端配置 → 已确认事项」展开。

---

## 一、申请类型与权限

| 申请类型 | 内容 | 可申请人员 |
|---|---|---|
| 请假 | 特休、病假、事假、婚假、丧假 | 全体考勤人员（管理员、运营负责人除外，见下） |
| 加班 | 来回路上时间 / 现场工作加班，结果转调休或加班费 | 仅工程师、司机 |
| 调休 | 使用调休余额 | 仅工程师（司机权限待放开） |

**几个前提：**
1. **管理员、运营负责人不能自助提交申请**（系统按"职责是审批他人"设计，提交时会提示审批流程为空）。
2. **来回路上时间只能转调休**，不能领加班费（选了会直接拦截）。
3. 调休补班日（周六调休上班）视为工作日，参与一切时长计算。

## 二、时长与日期计算（核心口径）

### 2.1 基本单位
- 每天工作 **8 小时**，半天 **4 小时**，请假以**半天**为单位增减（0.5 天 = 4 小时）。
- 半天槽位固定：
  - 上午 = 9:00–14:00（4 小时）
  - 下午 = 14:00–18:00（4 小时）
  - 全天 = 9:00–18:00（8 小时）
- 跨多天的申请，按起止日期逐天累计半天数。

### 2.2 哪些假别算自然日、哪些算工作日（重要）
| 假别/类型 | 计算口径 | 说明 |
|---|---|---|
| 特休、病假、事假 | **只计工作日** | 周六、周日、法定放假日全部跳过，不计入请假天数；调休补班日计入 |
| 调休、婚假、丧假 | **按自然日** | 六日也计入请假天数，不跳过 |
| 加班 | 见 2.3 | |

举例：某员工周一开始请"特休 3 天（对应 3 个工作日）"，若中间跨周末，实际占用周一至周五的日历区间。

### 2.3 加班时长计算（重要）
- **工作日（含补班日）**：计算 **上午 9:00 之前** 与 **下午 18:00 之后** 两段（早到晚走都算加班，产品裁决 2026-08-28）；9:00–18:00 正常时段不计；结束时间在 9:00 前或 18:00 后之外无加班。
- **周末、法定节假日**：全天计算。
- 取整规则：开始时间向上取整到整点、结束时间向下取整到整点（不满整点的零头舍弃）。
- 特例（保底）：**只要某一段确有实际发生的加班/路上时段（哪怕不足 15 分钟），该段掐整归零后一律按 0.5 小时计**；两段分别核算后相加（工作日最多两段各 0.5h 起）。
- 跨天边界取起始日定性（按开始日期判断是平日还是假日）。
- 去程/回程两段各自按上述规则计算后**相加**为路上总时长。

## 三、代理人规则（强制）

1. **请假、调休必须指定代理人**，没有代理人的申请无法提交（加班不需要代理人）。
2. 代理人不能是本人，须为系统启用的员工档案。
3. 审批顺序：**代理人先确认**（确认步骤排在审批链最前面），代理人同意后才进入后续正式审批。
4. 冲突校验（提交即拦截，重提时复核）：
   - 申请人在所选时段**已被他人指定为代理人** → 不能申请休假；
   - 所选代理人本人在该时段已有请假/调休（未终态）→ 必须更换代理人。
5. 同一代理人可以同时被多人指定。

---

## 四、审批流程（全角色明细，经实测验证）

### 4.1 基本链与追加终审
- 请假、调休、加班均走审批链，**所有角色按以下推导**（提交草稿时实时计算）。
- 追加「运营负责人终审」的触发条件（满足其一即追加）：
  1. **请假或调休达到 3 天**（含边界的精确说明见 4.3）；
  2. **台籍员工**（员工档案国籍为台籍）；
  3. 主管级申请人（工程主管、业务主管）。

### 4.2 各角色实际审批链一览（默认配置，实测）

| 申请人角色 | 请假/调休 不满 3 天、陆籍 | 请假/调休 满 3 天 或 台籍 | 加班 |
|---|---|---|---|
| 工程师 | 工程主管 → 行政主管 | 工程主管 → 行政主管 → **运营负责人** | 工程主管 → 行政主管 |
| 业务 | 业务主管 → 行政主管 | 业务主管 → 行政主管 → **运营负责人** | 业务主管 → 行政主管 |
| 助理 | **行政主管**（直属主管=运营负责人，自动跳过） | 行政主管 → **运营负责人** | 行政主管 |
| 调度 | 直属主管 → 行政主管 | 直属主管 → 行政主管 → **运营负责人** | （调度无加班权限） |
| 司机 | 直属主管 → 行政主管 | 直属主管 → 行政主管 → **运营负责人** | 直属主管 → 行政主管 |
| 采购 | 直属主管 → 行政主管 | 直属主管 → 行政主管 → **运营负责人** | （采购无加班权限） |
| 工程主管 | 行政主管 → **运营负责人**（无直属主管步骤） | 同左（恒含运营负责人） | 行政主管 |
| 业务主管 | 行政主管 → **运营负责人** | 同左 | 行政主管 |
| 行政主管本人 | **运营负责人** | 运营负责人 | 行政主管 → 运营负责人 |
| 运营负责人、管理员 | 无审批链 → **无法提交申请** | — | — |

> 有代理人时，表内链条最前面再加一步「代理人确认」。

### 4.3 "满 3 天"边界（重要）
- 满 3 天的判定按**该申请自身的假别口径**：
  - 特休/病假/事假：累计 **3 个工作日** 即触发；
  - 调休/婚丧假：累计 **3 个自然日** 即触发。
- 还会把**同一员工在此前已提交/已通过、尚未终态的其他请假/调休**连起来算：
  - 两份申请日期**相连**（相邻申请间只有周末或法定节假日相隔，视为相连）即合并累加；
  - 跨不同假别也合并（如：上周请了 2 天调休，这周再请 1 天病假 → 相连工作日累计满 3 天 → 追加运营负责人终审）。
- 追加终审是**链尾加一步**：代理人和前面各级审批都通过后，最后的运营负责人签核完才算批准；终审不是可选项。

### 4.4 审批权限边界
- **申请人不能审批自己的申请**（任何角色，包括管理员/行政主管）。
- **管理员、行政主管拥有全局审批权限**，可审批任意环节（防止审批链配置到的角色无人有权限时卡住）。
- 代理人确认步骤**只有被指定的代理人本人**可以批。
- 同一工单的多工程师加班申请作为**一组联动审批**：任一工程师的审批动作作用于整组（同进同退）。

## 五、证明材料

- **病假、婚假必须上传证明**（如病历、结婚证件），没有证明文件不能提交。
- 特休、事假、丧假、调休、加班：不需要证明材料。

---

## 六、休假余额（台账）

### 6.1 两种余额
- **特休**：单位天（0.5 天粒度）；审批通过按申请天数扣减（1 天 = 8 小时折算）。
- **调休**：单位小时（整小时）；加班转调休时按加班小时入账，调休申请按小时扣减。

### 6.2 入账/扣减时机（审批通过时自动发生）
| 场景 | 动作 |
|---|---|
| 加班（现场或路上）选择转调休，审批通过 | 调休余额 + 申请小时数 |
| 调休申请审批通过 | 调休余额 − 申请小时数 |
| 特休申请审批通过 | 特休余额 − 申请天数 |
| 申请撤回、作废 | 已入账/已扣减的余额**全额冲回** |

### 6.3 余额校验
- 调休、特休提交草稿时**前置校验余额**，不足直接拦截；审批到最后一关时**再次复核**，不足不能通过终审。
- 管理员操作：单笔调整（任意增减）、批量初始化（单次最多 200 人，把目标值写平，差额以调整记录留痕）。
- **加班费不做任何入账、不自动折算倍数**：系统仅在法定三倍工资日打角标提示，供审批与财务识别，实际金额由财务线下按法规计算。

---

## 七、法定节假日与三倍工资日

### 7.1 假期数据
- 内置假期：已公布年份 2025、2026（放假日 + 调休补班日），系统启动自动写入。
- 管理员可在「考勤设置 → 法定节假日」手动增删（临时调整或补充，手动项优先兜底）。
- 假期两种类型：**放假日**（加班全天计）、**调休补班日**（视为普通工作日）。

### 7.2 三倍工资日（全年 11 天，系统仅标注提示，不折算）
| 节日 | 天数 | 具体日期 |
|---|---|---|
| 元旦 | 1 | 1 月 1 日 |
| 春节 | 4 | 除夕、正月初一、初二、初三 |
| 清明节 | 1 | 清明节气当日 |
| 劳动节 | 2 | 5 月 1 日、2 日 |
| 端午节 | 1 | 农历五月初五 |
| 中秋节 | 1 | 农历八月十五 |
| 国庆节 | 3 | 10 月 1 日、2 日、3 日 |

> 系统按农历自动逐年计算以上日期（无需每年手工维护）；加班费按 1 倍计费、不自动乘 3，三倍差额由财务线下按法规计算。

## 八、值班

- 两种值班：**周末值班**、**法定节假日值班**。
- 排班方式：轮值（工程师按周轮流分配）或固定（指定人员在指定日期）。
- 模板按「年度 × 类型」维护成员顺序；支持一次排连续多天。
- 排班冲突：同一人同一天被排了两种值班会标记为待处理，由管理员人工消解；**法定节假日值班自动覆盖同日的周末值班**（避免重复）。
- 月度流程：排班草稿 → 主管提交 → **行政批准/驳回**；被驳回可修正后重新提交。

---

## 九、报表（月报导出）

- 导出 Excel 月报，按所选月份与筛选条件统计特休、加班、请假等；
- 支持单月/跨月（上限 366 天，年度内范围）；
- 加班时段裁剪到所选日期范围；含员工在职状态、审批终态时间列。

---

## 十、申请状态流转（速查）

```
草稿 → 待代理人确认 → 待审批（各审批步骤依次）
     → 已通过（自动结算余额）/ 已驳回 / 已撤回 / 已作废
```
- 审批步骤状态：等待、待签核、已通过、已驳回、已跳过。
- 系统通知：提交申请、轮到下一步审批、驳回、最终完成均有站内/邮件通知。

---

## 十一、管理端可配置项（人工维护）

1. **员工档案**：国籍（陆籍/台籍——决定台籍终审）、特休规则标签、直属主管；
2. **审批角色规则**：各申请人角色对应的直属主管角色（默认映射见核对表）：
   - 工程师 → 工程主管；业务 → 业务主管；助理/调度/采购等默认直属主管为运营负责人（助理因此自动跳过主管步骤，只到行政主管）；
   - 工程主管、业务主管 → 运营负责人（作为申请人时的直属主管映射）；
3. 法定节假日：内置自动 + 手动增删；
4. 特休/调休余额：单笔调整 + 批量初始化；
5. 值班模板与月度排班批次。
