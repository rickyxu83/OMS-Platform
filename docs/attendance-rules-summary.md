# OMS 考勤模块规则与逻辑说明（供行政审核核对）

> 依据 backend/src/modules/attendance/*（controller / workflow / duty / report / holiday-sync / triple-pay-days）与前端 attendance-shared.ts 源码梳理，2026-08-28。
> 本文按「申请类型 → 时长口径 → 代理人 → 证明 → 审批链 → 余额台账 → 节假日 → 值班 → 报表」展开，标注了源码出处与产品裁决日期，方便逐条核对公司制度是否有遗漏。

---

## 一、申请类型与角色门禁

| 申请类型 | 说明 | 适用角色 |
|---|---|---|
| `leave` 请假 | 假别 5 种：特休、病假、事假、婚假、丧假 | 全体考勤角色（见下方注意） |
| `overtime` 加班 | 加班种类 2 种：`travel` 来回路上时间 / `work` 工作加班；处理结果 2 种：转调休 / 加班费 | **仅工程师、司机** |
| `comp_time` 调休 | 使用调休余额 | **仅工程师、司机** |

注意：
- 调休与加班均仅工程师与司机可申请为产品裁决（2026-08-28），主管及其他角色无这两个申请入口；无调休资格角色的页面不再显示调休余额。
- 管理员、运营负责人因审批链为空（见第四节），实际无法自助提交申请（提交时报「审批流程不能为空」）——属既有设计，其职责是审批他人。
- 加班种类 `travel`（来回路上时间）**只能转调休**，不能选加班费（`travel + pay` 直接拦截）。

## 二、时长与日期计算口径

- 每天工作 8 小时，半天 = 4 小时；**请假时长必须以半天为单位**（0.5 天 = 4h）。
- 半小时槽位固定：上午 09:00–14:00（4h）、下午 14:00–18:00（4h）、全天 09:00–18:00（8h）。跨天请假按起止半天槽累计。
- **不含六日与法定节假日**的假别：特休、病假、事假（只累计工作日）。
- **含六日（自然日口径）**的假别/类型：调休、婚假、丧假。
- 调休补班日（makeup_workday）视为工作日参与计算。
- 加班时长核算（2026-08-25 定稿，见 docs/adr/0002）：
  - 工作日只计 **09:00 上班前 + 18:00 下班后**（工作时间内的部分不计加班）；结束时间 ≤ 18:00 则无加班。
  - 休息日 / 法定节假日：全天计。
  - 开始向上取整点、结束向下取整点；有效时长按 **0.5h 粒度四舍五入**（满 15 分钟进 0.5h）。
  - 掐整后归零但确有加班事实（如节假日路上 25 分钟）→ 按 0.5h 保底（2026-08-27 裁决）。
  - 跨天时边界取起始日。
  - 前端 `previewOvertimeHours` 镜像同一口径做即时预览，改动规则需两边同步。

## 三、代理人规则（2026-08-28 恢复确认环节）

- 请假、调休**必须选择代理人**，代理人不能是本人；代理人须为启用考勤的员工档案。
- 代理人确认步骤插在审批链**首部**（delegate 步骤），代理人同意后才进入后续审批。
- 冲突校验（提交即拦截，草稿提交时复核）：
  1. 申请人在所选时段**已被他人指定为代理人** → 禁止休假；
  2. 所选代理人本人在申请时段已有请假/调休（未终态）→ 需换代理人。
- 代理人可同时被多人指定。

## 四、审批链（v4 自动推导，2026-08-28）

提交草稿时按「申请人角色 + 当前直属主管映射 + 假期参数」实时推导，配置变更对未提交草稿即时生效：

| 申请人 | 审批链 |
|---|---|
| 普通员工（工程师/业务/助理等） | 直属主管 → 行政主管 |
| 主管级（工程主管 / 业务主管） | 行政主管 → 运营负责人（无直属主管步骤） |
| 行政主管本人 | 运营负责人 |
| 管理员 / 运营负责人 | 空链（提交报「审批流程不能为空」，见第一节注意） |

末尾追加「运营负责人终审」的三种情形：
1. **请假/调休满 3 天**（含跨假别相连工作日累计：跨周末/法定节假日不阻断相连，跨调休补班日可接续；`connectedLeaveWorkingDays` 会把同一员工处于审批中/已通过的所有未终态申请按相连合并累计）；
2. **台籍员工**（员工档案 nationality = taiwan）申请请假/调休：末尾固定运营负责人（mich 林智强）；
3. 主管级申请人（情形 1 已含）。

审批权限边界：
- **申请人不能审批自己的申请**（无论角色）。
- 管理员、行政主管拥有全部考勤审批权限，可审批任意环节（防止审批链配置的角色无权限时卡死）。
- 代理人步骤仅指定代理人本人可批。
- 同工单加班组（batch_id）联动：任一条目的审批动作扩展到整组同事务处理。

## 五、证明要求

- **病假、婚假必须上传证明**（附件 purpose = leave_proof），提交草稿时强制校验，无附件不能提交。
- 其余假别（特休、事假、丧假）与调休、加班无需证明。

## 六、余额台账（attendance_balance_ledger）

- 余额类型：**特休（单位：天）**、**调休（单位：小时）**；余额 = 台账 delta_hours 累计（幂等、防并发：row lock）。
- 入账时机（审批通过时自动结算）：
  - 加班（work/travel）→ 转调休：通过后 +h 入账「加班转调休」；
  - 调休申请通过：−h（若余额不足拦截终审）；
  - 特休申请通过：−天数（hours÷8）（提交时前置校验余额，终审再复核）；
- 撤回 / 作废：台账冲回（void 冲回）。
- 管理端操作：单笔余额调整、批量初始化（单次 ≤ 200 人；特休按天、调休按小时设定目标值）。
- 加班费（pay）费率：**统一 1 倍按申请时长计**。三倍折算已取消（2026-08-21 裁决）：系统不做 300% 折算，由行政线下按法定节假日法规自行计算；系统仅以「三倍工资日角标」（isTriplePay）提示审批人与财务。

## 七、节假日与三倍工资日

- 数据源四种：内置 `builtin`（启动幂等种子，已公布年份 2025、2026）、手动 `manual`（管理端「考勤设置→法定节假日」增删，兜底）、自动 `auto`（次年节假日同步）。
- dayType 两种：`legal_holiday` 法定放假日（加班全天计）、`makeup_workday` 调休补班日（视为工作日）。
- 三倍工资日（lunar-javascript 按年份自动计算，仅角标提示，不折算）：元旦 1 天 + 春节 4 天（除夕、初一、初二、初三）+ 清明 1 天 + 劳动节 2 天 + 端午 1 天 + 中秋 1 天 + 国庆 3 天 = **共 11 天**。

## 八、值班（Duty）

- 值班类型：`weekend_on_call` 周末值班、`legal_holiday_on_call` 法定节假日值班。
- 排班模式：`rotation` 轮值（工程师按周轮流） / `fixed` 固定（指定全员每天）。
- 模板按「年度 × 类型」维护成员顺序；记录支持连续段（duty_end_date 展开）；同一员工同日期多类型标记 overlap 需人工消解。
- 节假日优先自动消解：法定节假日段覆盖的每一天（含周末）自动删除同工程师当日周末值班记录。
- 月度批次流转：`draft`（排班草稿）→ 主管提交 → `pending_admin` → 行政批准 / 驳回。

## 九、报表

- 管理端「月报导出」：Excel 表，范围上限 366 天，按筛选条件统计特休/加班/请假等（加班时段裁剪到所选日期范围），含员工在职状态与审批终态时间列。

## 状态流转速查

```
草稿 draft → pending_delegate（待代理人）/ pending_approval（待审批 role）
          → pending_hr（旧流程人事）/ pending_vp（旧流程副总）/ pending_admin（旧流程行政）
          → approved（已通过，自动落台账）| rejected / withdrawn / voided
```

- 审批链步骤状态：waiting → pending → approved / rejected / skipped。
- 通知：提交、下一步审批、驳回、完成均触发邮件/站内通知（attendance-notifications 服务）。

## 管理端可配置项（人工维护）

1. 员工档案：国籍（陆籍/台籍，决定台籍终审）、特休规则标签（annual_leave_rule，默认随国籍）、直属主管；
2. 审批角色规则：各申请人角色 → 直属主管角色映射（v4 推导实时生效）；
3. 法定节假日：内置自动 + 手动增删（补班/放假）；
4. 特休/调休余额：单笔调整 + 批量初始化；
5. 值班模板与月度排班批次。
